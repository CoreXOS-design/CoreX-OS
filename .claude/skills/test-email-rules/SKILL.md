# Test-email / outbound rules

- **A QA/test click must never reach a real person.** Outbound is neutralised on QA (mail to log/localhost, WAHA blanked, PP/Firebase blanked). Any new integration a lane adds must be inert on QA before Johan QAs a send path (see `/corex-qa1/NOTES-FOR-ANDRE.md`).
- **Outbound mail guard** (spec `.ai/specs/outbound-mail-guard.md`): sending is real only when `APP_ENV=production` AND a production host (`corexos.co.za`, `www.corexos.co.za`) AND `OUTBOUND_MAIL_REAL_SEND=1`. The flag is set by hand on the real live server ONLY (62.238.31.82); it must be ABSENT on Staging, QA1, QA2, demo, live-testing and local, and `deploy.sh staging` refuses if set. Never copy live's `.env` to another box without deleting that line. `deploy.sh production` refuses without it. Runbook: `.ai/runbooks/outbound-mail-real-send-flag.md`; verify on live with `App\Support\OutboundMailGuard::isSendingConfirmed()` in tinker.
- **On QA1:** mail is held by the guard - delivered to Mailpit at `outbound-guard@localhost.test`, subject prefixed `[GUARDED]`, the real recipient only in the message text. Inspection/signing/e-sign mail goes through `SignedDocumentDistributionService`, which SUPPRESSES everything off-production unless `MAIL_NON_PRODUCTION_REDIRECT` is set (QA1: `can.assurance@gmail.com`, SMTP leg to Mailpit 127.0.0.1:1025). Mailpit UI is 127.0.0.1:8025 (not reachable from outside; `mail.demo1.corexos.co.za` proxies to this box's own Mailpit and is shared by QA1/QA2/Staging/Demo; `MAILPIT_UI_URL` has no default).
- **Prove a send** with rolled-back tinker (status "sent"), then read Mailpit: `curl 127.0.0.1:8025/api/v1/messages` - search by subject + text, not `to:`. OTP codes have a 60 s per-address cooldown (429, no mail) - wait it out.
- **Test recipients:** only `can.assurance@gmail.com` contacts. QA1 fixtures: lease 21 / property 21062 (tenant 19078, landlord 19079), lease 8 / property 21044 (tenant 19070, landlord 19071 has no email). Lease 20's contacts are archived; **lease 94's tenant is a REAL address - never mail-test there.** Real-agency mailboxes are never used for test connections.
- **Mailbox safety (Afrihost IP-ban incident, Sep 2026):** Test Connection clicks, IMAP polls and retries are rate-limited with an auth-failure lock, circuit breaker and back-off; chunked polling checkpoints per chunk. Never loop real logins against a provider; `ImapMailboxPoller::connect()` still has no env guard. Detail: `.ai/deploy/2026-09-10-email-safeguards-live-handover.md`.
- Staff-facing mail carries the `StaffFacingMail` marker; a contact with no email is NOT sent and the gap is visible to the user.
