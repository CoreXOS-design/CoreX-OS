# Daily-activity points: before and after the one shared rule (Agency Tracker re-home, step 3)

Prepared 21 Oct 2026 for Johan, from the real QA1 data (read-only). Ticket AT-475.

## In plain words

- **Every screen now adds up points the same way.** Before, about a dozen screens each had their own sum and they did not all agree on which activities count. Now there is one rule, written once.
- **Nobody's total changed.** I compared every agent for every month from June to October (90 agent-months). The old screens and the new rule give the **same number for all 90.** Past months keep exactly the totals they had; nothing already earned was rewritten.
- **One fix goes forward only.** Calendar credit (a viewing, an evaluation, a presentation) was being counted at its points value *times itself*: one presentation scored 40,000 instead of 200. From today a calendar event counts once (200). The two calendar events still waiting for feedback were corrected too, because they are not yet part of anyone's total.
- **If an agency switches an activity off, points already earned from it still count** (before, some screens dropped them and some kept them, so the same agent showed two different numbers).
